R1 correction
-------------
The Windows legacy comprehensive self-test previously treated the literal
`personage-default` inside the subject-page DOM script as evidence that the
application visited person-profile pages. That literal is only a rejection
pattern for Douban's default placeholder avatar.

The corrected test now:
- rejects actual profile-page fallback/navigation indicators such as
  `matching-img`, `fetch(profileUrl`, `location.href=profileUrl`, and
  `window.open(profileUrl`;
- separately verifies that `personage-default` placeholder images continue to
  be filtered.

No detail-loading, cast-loading, review-writing, caching, or WebView2 runtime
logic changed in R1.
