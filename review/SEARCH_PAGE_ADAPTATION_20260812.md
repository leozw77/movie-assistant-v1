# v1.0 搜索页面适配交接 - 2026-08-12

## 发布身份

- 产品：观影助手
- 渠道：v1.0 独立试用版
- 当前范围：Douban Plus 搜索页适配
- 正式基线：v0.9.0 BuildFix12 R11，保持不变
- 正式发布目录：不得修改 `D:\chatgpt\观影助手\发布版本`

## 本轮业务范围

1. 豆瓣页面切换期间隐藏本地影视库 WebView。
2. 保留本地 JSON、详情缓存、评价事务、Worker 队列和消息桥接作为后台依赖。
3. 将 `search.douban.com/movie/subject_search` 的官方结果 DOM 重绘为统一深色页面。
4. 接入搜索结果卡片、海报、标题、元信息、分页和影片详情入口。
5. 修复搜索结果适配只识别完整绝对链接、且只扫描首屏 DOM 导致有结果时显示空状态的问题。
6. 详情页评分数字、星级和评价数固定为高亮同组；详情返回按来源恢复 Douban Plus 搜索页或个人页。
7. 搜索结果卡片将评分、评价人数、年份、可播放状态、影片事实和主创信息结构化分层，评分行禁止换行，事实项独立换行。
8. 搜索结果卡片移除顶部绿色结果标识、可播放标签和评分后的尾部小数字；海报必须保持原始比例，不裁切、不拉伸。

不在本轮范围：待看按钮、右键菜单、搜索结果卡片内的状态写入、正式版升级、删除本地数据文件。

## 技术边界

- 搜索结果只读取官方搜索页已经加载的 DOM，不新增第二套搜索数据源。
- 结果链接兼容绝对、协议相对和相对 `/subject/{id}/` 形式，并规范化到真实影片详情 URL。
- 搜索页监听官方结果区域的延迟 DOM 插入，最多等待 10 秒；拿到结果后立即停止监听。
- 详情页评分数字、星级和评价数不得被 CSS 网格拆到错误行；国家、年份、时长保持不可拆分，类型标签独立换行。
- 搜索结果评分必须独立高亮；评价人数不能与标题或事实文本混在同一段；事实项逐项换行，不允许整段原始文本随机截断。
- 详情返回只恢复记录的 Douban Plus 来源页；新版详情没有来源时不显示返回按钮，不再回退到本地库。
- 搜索框继续复用 `SubjectSwitcher`。
- 结果详情使用真实 `/subject/{id}/` 同窗口导航。
- 本地影视库视图只隐藏，不删除；新版搜索页和个人页不显示“影视库”返回入口，避免误回旧界面。
- 适配失败时不得把本地影视库自动切回前台。

## 交付规范

- 每次交付使用新的不可覆盖目录。
- 交付目录必须包含 EXE、版本元数据、版本说明、自检结果和 `SHA256SUMS.txt`。
- EXE 必须为 Windows x64 framework-dependent single-file，依赖 .NET 8 Desktop Runtime 和 WebView2 Evergreen Runtime。
- 正式 v0.9.0 EXE、ZIP、发布目录和哈希不得被覆盖。
