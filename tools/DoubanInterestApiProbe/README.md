# Douban Interest API Probe

独立测试工具，不修改观影助手稳定逻辑。

## 目的

验证豆瓣网页自身的直接 HTTP 接口：

- 想看 wish、在看 do、看过 collect
- 1 至 5 星评分和短评
- 官方 remove 完整删除
- GET /j/subject/{id}/interest 的 JSON 字段和内嵌 html
- GET /subject/{id}/ 的状态、评分、短评、标记日期

## 使用

1. 启动程序，在中间内嵌 WebView2 登录豆瓣。
2. 点“检查登录状态”，确认检测到 ck。
3. 输入 Subject ID。
4. 首先点“读取双端点”。工具同时读取兴趣 JSON 和影片 HTML，输出字段是否缺失、为空或解析成功。
5. 如需验证写入闭环，选择状态、评分和短评后点“写入后回读”。按钮会二次确认，写入后自动读取两个 GET 端点。
6. 如需验证完整删除，点“删除后回读”。工具会记录 /remove 的状态码和 Location，再读取两个 GET 端点。
7. “打开 v2 写入窗口”和“打开 v5 删除窗口”保留旧版实验入口。

## 安全与边界

- 启动时不会自动写入。
- 不保存账号密码。
- Cookie 只从本程序自己的 WebView2 会话读取；日志只显示 Cookie 名称，不显示值。
- 写入和删除都会二次确认。
- 默认不输出完整响应正文，只输出长度、字段类型、字段样本和解析结果，避免把登录态页面内容写入日志。
- 不批量写入，不自动重试写请求。
- HTTP 2xx 不直接视为最终成功；应以逐字段回读和豆瓣网页人工确认作为证据。

## 说明

v6 的目标是把“写入请求成功”和“官方回读完全一致”分开，为以后只在确认后更新本地 SQL 提供验证基础。该工具不是 frodo.douban.com 的私有写接口，也不是主程序正式写入流程。
