## v0.8.9 核心能力

- 保留 .NET 8 WinForms 托盘、PotPlayer、爱奇艺、提醒、AI 与本地数据链路。
- 使用本地 HTML/CSS/JavaScript 实现影视库、分页、搜索、详情和演职员界面。
- 使用观影助手专用 WebView2 Profile 展示豆瓣官方扫码登录页，不复制、输出或导出 Cookie 值。
- 登录状态与在线同步状态分离；保存 Profile ID 后直接读取当前账号 `people/{id}/collect|wish|do` 页面。
- 界面明确显示豆瓣登录状态以及在线或本地缓存数据来源。
- 登录窗口与后台同步互斥，避免同一 Profile 的并发导航和 WebView2 进程冲突。
- 内置 WebView2 连接器优先，既有 Chrome/Edge CDP 链路继续作为受控回退。
- 演员与海报继续使用豆瓣原始图片 URL、WebP/JPEG 兼容和受控本地缓存；不使用截图或第三方人物 API。

## 数据与兼容边界

- 豆瓣会话状态记录在 `%LOCALAPPDATA%\DoubanBrowserReminder\douban-session.json`，Cookie 仍由 WebView2 Profile 管理。
- 豆瓣历史、在线搜索缓存和软件观看记录继续分开保存。
- 本版本只读取豆瓣数据，不自动写入想看、在看、看过、评分、标签或短评。
- 缺少 WebView2 Runtime 时应显示中文说明和微软官方安装入口；非 Web 功能尽量保持可用。
- 豆瓣 DOM、图片链接和风控规则将来可能变化；失败时保留本地数据，不使用截图兜底。
